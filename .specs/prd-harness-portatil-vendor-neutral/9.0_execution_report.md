## Riscos Residuais
- [LOW] A detecção de destrutividade é heurística baseada em regex sobre tokens do comando (`rm` + flags recursivo/forçado); não cobre remoção recursiva por outros meios (`python -c "shutil.rmtree(...)"`, `find / -delete`, `git clean -fdx` como possível vetor destrutivo adicional). Fora de escopo desta tarefa por design (ver Suposições); ADR-005 já antecipa essa fronteira e prevê substituição por catálogo declarativo caso o critério precise crescer.
- [LOW] `git-operation-gate.sh` reconhece `git commit`/`git push` via regex tolerante a flags intermediárias (`git -C repo commit ...`), mas não desambigua `push`/`commit` usados como argumento de outro comando (ex.: `echo "please commit"`) — falso positivo teoricamente possível, mitigado pelo escape auditado `GOVERNANCE_GIT_OPERATION_CONFIRMED=1`.
