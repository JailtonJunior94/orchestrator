## Suposições

- O binário `claude-agent-acp@0.1.0` não está disponível no ambiente local (npm erro ETARGET). Testes que chegam até o spawn do runner encontram erro de probe — comportamento esperado em CI sem o binário. A lógica de spawn foi validada pelo `TestSpawnNestedSessionEvidenceDirCreated` que verifica criação do dir antes do erro de probe.
- A env var `AISPEC_RUN_AGENT_CONTEXT` é setada/restaurada via `os.Setenv`/`os.Unsetenv` no mesmo processo. Em produção, o child runner herda o processo via exec do launcher — o padrão de injeção via env var está correto para ambos os casos.
- `internal/parity/invariants.go` com INV-30/INV-31 será adicionado na task 2.0 (task file própria).

## Riscos Residuais

- Wire minimal implementa apenas os métodos MCP necessários (`initialize`, `tools/list`, `tools/call`, `notifications/initialized`). Clientes MCP que enviem outros métodos receberão `ErrCodeMethodNotFound` corretamente.
- Env var `AISPEC_RUN_AGENT_CONTEXT` usa `os.Setenv`/`os.Unsetenv` que não são goroutine-safe. Em cenário de chamadas paralelas de `run_agent`, pode haver race. Mitigação para task 3.0: usar contexto Go ao invés de env var para injeção interna. Para esta task, o comportamento de produção (fork de child process) não tem o problema — apenas o mock in-process.
- `buildSummaryText` cobertura 0% — função simples chamada indiretamente após spawn bem-sucedido; não há binário em CI. Aceitável: cobertura do subpacote (82.1%) acima do threshold.
