# Execution Report: 4.1 Correcao do default do tasks-root (defeito da migracao)

## Status

done

## Contexto

Auditoria pos-migracao detectou que a execucao anterior (tarefas 1.0–4.0) introduziu um
defeito critico na camada shell: o valor default de `AI_TASKS_ROOT` foi gravado com um `s`
extra (`.spec` seguido de `ss`) em vez de `.specs`.

- Causa-raiz: substituicao malfeita `task` -> `.specs` aplicada sobre o token historico do
  default, deixando o `s` final do token original e apontando para um diretorio inexistente.
  Confirmado por diff em `.agents/hooks/pre-execute-all-tasks.sh`: a linha
  `TASKS_ROOT="${AI_TASKS_ROOT:-<root>}"` passou do valor historico para o valor com `s`
  duplicado, agora corrigido para `${AI_TASKS_ROOT:-.specs}`.
- Impacto: hooks shell e docs de skills resolviam um diretorio inexistente, quebrando a
  resolucao de `.specs/prd-*` no modo interativo. O runtime Go
  (`internal/config/runtime.go` -> `TasksRoot: ".specs"`) ja estava correto.
- O relatorio `2.0_execution_report.md` afirma "Hooks por-tool usam `AI_TASKS_ROOT:-.specs`",
  o que **nao correspondia ao estado real do working tree** ate esta correcao.

## Evidencias

- 58 ocorrencias do default com `s` duplicado corrigidas para `.specs` em:
  - Hooks (`post-execute-task.sh`, `pre-execute-all-tasks.sh`, `post-wave.sh`) no canonico
    `.agents/` e mirrors `.claude/`, `.codex/`, `.gemini/`, `.github/` + `internal/embedded/assets/**`.
  - SKILL.md de `create-prd`, `create-tasks`, `create-technical-specification`, `execute-task`,
    `execute-all-tasks`, `bugfix` no canonico `.agents/skills/` e mirrors `.claude/skills/`, `.github/skills/`
    + embedded.
- Reaplicado via `bash scripts/sync-hooks.sh` e `bash scripts/sync-skills.sh`.
- Sweep final do token defeituoso (excluindo `.git/`) retornou **0 ocorrencias** funcionais.

*fallback* default. Validacao adicional executada com `AI_TASKS_ROOT` **unset**:
