## Suposições
- O formato exato dos argumentos `input`/`output` do hook `tool.execute.before` do OpenCode (`{tool, sessionID, callID}` / `{args}`) foi inferido das evidências V-04/V-05 do PRD e confirmado indiretamente pelo teste live `TestACPLive_OpenCode_HandshakeSucceedsWithRealPlugin`, que carrega e executa o plugin real dentro de um `opencode acp` real sem erro de carregamento. Não foi possível confirmar o shape exato de `output.args` por tool sem uma sessão autenticada disparando uma tool call real (fora do escopo desta tarefa — camada 3, nightly).
- "Runtime necessário ao plugin" (RF-23) foi interpretado como `bash`, por ser a dependência concreta que o plugin invoca via `spawnSync` para delegar ao script canônico `.agents/scripts/hook-prereq-gate.sh`. Alternativa descartada: Node/Bun, pois já é dependência transitiva do próprio `opencode`.
