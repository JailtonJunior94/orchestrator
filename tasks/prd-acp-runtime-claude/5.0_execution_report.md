## Decisões Técnicas

1. **Cache via `sync.Map` + `sync.Once`**: A task pedia `sync.OnceValues`-style. Implementado com `cacheEntry{once sync.Once, launcher, err}` + `sync.Map` para suportar múltiplas specs diferentes com cache independente por `spec.ID`.

2. **`findLastAt` busca último `@`**: Pacotes npm scoped (`@scope/pkg@ver`) têm `@` no início do scope. Buscamos o último `@` para separar o pacote da versão corretamente.

3. **Import de `runtime.ErrLauncherUnavailable`**: O sentinel está em `internal/runtime/errors.go` (criado na task 6.0). O probe importa do pacote pai (`internal/runtime`) sem circular dependency.

4. **`ResetCache` exportado**: Necessário para que testes possam isolar estado de cache entre si. Documentado como "apenas em testes".
